# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Saddalayogesh/frontend-development.git
```

### Navigate into the Project

```bash
cd frontend-development
```

### Run HTML/CSS/JS Projects

Open the corresponding `index.html` file in your browser.

### Run React Projects

```bash
cd react-programs/<project-name>

npm install

npm run dev
```
