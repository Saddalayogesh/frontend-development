# 🚀 Frontend Development Learning Hub

Welcome to my **Frontend Development Learning Hub**! This repository documents my journey of learning modern frontend web development through hands-on practice, coding exercises, and mini-projects. It includes examples built with HTML, CSS, JavaScript, and React.js, organized by technology for easy navigation and continuous learning.

## 📂 Repository Structure

```text
frontend-development/
├── css-fundamentals/         # CSS layouts, Flexbox, Grid, animations
├── html-fundamentals/        # HTML elements, forms, tables, semantic tags
├── javascript-fundamentals/  # JavaScript concepts, DOM, ES6, events
├── react-programs/           # React applications and practice projects
└── fresh-mart-project/       # Grocery website frontend project
```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Saddalayogesh/frontend-development.git
```

### Navigate to the project

```bash
cd frontend-development
```

### Run HTML/CSS/JavaScript Projects

Open the corresponding `index.html` file in your browser.

### Run React Projects

```bash
cd react-programs/<project-folder>
npm install
npm run dev
```

The application will start on the local development server.
